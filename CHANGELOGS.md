# Изменения

## Pre-release — 2026-10-23

- Очередь в MongoDB заменена Celery, RabbitMQ и Redis.
- Добавлены checkpoints, leases, ограниченные повторы и восстановление через beat.
- Устранены гонки записи, повторного запуска и сохранения оценок.
- Исправлены LTI-запуски, изоляция LMS, доступ к файлам и проверки входных данных.
- Отправка оценки в LMS использует таймауты и сохраняет оценку при сбое доставки.
- Конфигурация перенесена из INI в Python; секреты и concurrency читаются из окружения.
- Flask создаётся фабрикой с локализацией и отдельными экземплярами для тестов.
- Compose запускает все сервисы; сборка не требует внешнего базового образа.
- Служебные очереди Celery совместимы с RabbitMQ 4.3; тег приложения общий.
- Удалены старые процессоры, Vosk, тестовые заглушки и неиспользуемые методы.
- Убраны неиспользуемый runtime-denoiser, его устаревшие тесты и лишние зависимости;
  исследовательская реализация сохранена в playground.
- PDF читается без временных текстовых файлов; NLTK нужен только для оценки.
- Исправлены экспорт BSON ZIP через API и скрипт полного резервного копирования.
- Исправлены авторизация чтения критериев/наборов и ответ для неизвестного критерия.
- Добавлены юнит-тесты, Selenium и проверки отказов настоящих брокера/воркеров.

### При обновлении

Используйте `APP_CONF=../app_conf/config.py`, заполните `.env` по примеру и
сделайте полную копию MongoDB/GridFS. Старые DB-процессоры должны быть остановлены.
Создание экспорта через API теперь использует POST вместо GET.
