# Проверка pre-release — 23 октября 2026

Стек `wst-real-tests`: Docker Engine 29.9.2, Python 3.11, MongoDB 8,
RabbitMQ 4.3.6, Redis 7, Celery 5.6.2, Whisper v1.3.0 с моделью `tiny`.
Selenium использовал Chrome/ChromeDriver 137 внутри Docker.

| Проверка | Результат |
|---|---|
| Юнит-тесты внутри финального образа | 194 прошли, 5 интеграционных пропущены |
| Selenium после проверок отказов | 9 прошли, 35,16 с |
| Реальные API и проверки отказов | 5 прошли, 304 с |
| Восстановление ZIP-экспорта через mongorestore | 100 документов, 0 ошибок |

Проверены запись и загрузка, оценка, назначенная презентация, повторный запуск,
администраторский recheck, страницы и API, BSON/GridFS-экспорт, пересоздание
RabbitMQ, недоступность брокера при публикации и SIGKILL активного аудиоворкера.
После отказов workflow завершался с сохранением run и всех шести checkpoints.

В тестах отказов использованы soft/hard/lease 150/180/190 с. Рабочие значения
1500/1800/1860 с не уменьшались. Данные хранились в отдельных тестовых томах.
Проверки отказов и обычный Selenium выполнялись последовательно.

MongoDB, брокер, воркеры и распознавание не подменялись. Testing-профиль отключает
проверку LTI-подписи и отправку во внешнюю LMS. Настоящая Moodle не проверялась.
Команды воспроизведения — в [README](../README.md#тесты).
