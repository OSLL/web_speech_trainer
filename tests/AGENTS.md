# Тестирование

Дополняет корневой AGENTS.md.

- `tests/conftest.py` изолирует MongoDB для каждого юнит-теста. Используйте фикстуры
  `database` и `app`; не импортируйте глобальное Flask-приложение.
- Сохраняйте временные результаты в `tmp_path`; не перезаписывайте аудиофикстуры.
- Случайные данные делайте воспроизводимыми. Для независимых запусков LTI используйте
  уникальные task IDs, чтобы реальная БД не ломала повторный прогон.
- Selenium должен проверять видимый результат и давать ограниченное время ожидания.
  ChromeDriver берётся из Docker-образа; API-клиент переносит cookies с учётом
  однословного Docker hostname.
- `integration` запускается только с `--integration`. Проверки отказов требуют
  `WST_FAULT_TESTS=1` и отдельного testing Compose-проекта.
- Проверяйте завершение всех этапов и сохранение run после сбоя. Не считайте
  перезапуск контейнера доказательством восстановления бизнес-операции.
- Testing-профиль отключает подписи LTI и запросы во внешнюю LMS. Это ограничение
  указывайте в результатах; реальную LMS не подменяйте молча.
- В отчёте отличайте юнит-тесты, Selenium, проверки отказов и пропущенные тесты.
