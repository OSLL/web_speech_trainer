# Наборы критериев

`BaseCriterionPack` применяет критерии и собирает их результаты.
`CriteriaPackFactory` читает состав набора из MongoDB. Стандартные наборы
создаются командой `python3 -m app.bootstrap`.

Вес каждого критерия хранится в `criterion_weights`. Итоговую оценку вычисляет
`FeedbackEvaluatorFactory`. Ошибка критерия прерывает этап: частичный результат
не выдаётся за успешную обработку.

Чтобы добавить набор, задайте его состав и веса в `preconfigured_pack.py`.
Проверьте обычную тренировку, пустые данные и ошибку одного из критериев.
