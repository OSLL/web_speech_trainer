# Чтение презентаций

`slide_splitter.parse_pdf()` возвращает исходный текст каждой страницы PDF.
Документ закрывается после чтения; промежуточные файлы не создаются.

При загрузке PPT, PPTX и ODP приложение сначала преобразует файл в PDF через
LibreOffice. Превью создаётся через PyMuPDF. Лимиты и MIME проверяются в API.

`ppt_parser.py` и `odp_parser.py` поддерживают соответствующие распознаватели
в `app/presentation_recognizer.py`. Зависимости устанавливаются из корневого
`requirements.txt`.
