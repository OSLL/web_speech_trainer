# Runtime

Дополняет корневой AGENTS.md.

- Создавайте Flask через `create_app()`. Не добавляйте глобальный экземпляр app.
- `Config.c` и locale общие для процесса. Выбирайте конфиг до создания приложения.
- Схему и начальные данные меняйте через bootstrap; фабрика их не изменяет.
- Запись training выполняйте атомарно с фильтром текущего run/stage owner.
  Не сохраняйте целый загруженный документ поверх параллельных изменений.
- При новом run повышайте generation. Запись оценки в attempt должна быть
  ограждена run/generation, а внешняя доставка — lease и revision.
- Этапы оформляйте через `@stage`. Повторная доставка должна использовать checkpoint.
  Не подавляйте ошибки распознавания и критериев пустым «успешным» результатом.
- Не уменьшайте lease ниже hard task limit. Сохраняйте ограничение попыток.
- GridFS-артефакты этапов используют детерминированные ID. Закрывайте streams,
  временные файлы, PDF и курсоры даже при исключении.
- Проверяйте владельца и consumer_key на сервере для каждого объекта.
- Изменения статусов должны сохранять вычисленную оценку при отказе LMS.
- Критерии зарегистрированы через `criteria/criterions.py`; эти импорты нужны,
  даже если статический анализ помечает их как неиспользуемые.
- `flower_app.py` не должен импортировать задачи и конфигурацию Flask.
- NLTK stopwords нужны для критериев оценки; не добавляйте зависимость всем сервисам.
