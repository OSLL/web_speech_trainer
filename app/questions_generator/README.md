## Запуск

Из корня проекта, с настроенным окружением основного Compose:

```bash
docker compose up -d --build --wait worker_questions
```

Воркеры используют RabbitMQ и Redis основного стека, Python-конфиг APP_CONF и
отдельную очередь question_generation. Генератор поддерживает DOC/DOCX;
NLTK и LibreOffice Writer установлены в отдельном образе Python 3.11.

Веб-сценарий включает эвристические/статические вопросы. LLM-код сохранён,
но отключён в веб-сценарии, а его сервис не входит в основной Compose.
