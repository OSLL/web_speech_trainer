# Настройки вопросов интервью: что изменилось и как проверить

## Что изменилось

Раньше набор вопросов собирался так: максимум вопросов по задачам работы (эвристические правила),
остаток добирался из общего CSV-пула. Повлиять на соотношение или сложность было нельзя.

Теперь:

- у каждого вопроса есть **тип**: `specific` (построен по тексту работы, по задачам) или `general` (подходит любой работе, из CSV);
- у каждого вопроса есть **сложность**: `easy`, `medium`, `hard`. Для шаблонов правил она задана в `heuristic_templates.py`,
  для общих вопросов её можно указать в необязательном столбце `difficulty` CSV (нет столбца - `medium`);
- модуль `app/questions_generator/question_composer.py` собирает набор по настройкам
  `QuestionSettings(count, specific_share, difficulty)`.

## Значения по умолчанию в конфиге

Если в запуске LTI параметров нет, берутся значения из конфига (`app_conf/config.py`, `app_conf/testing.py`):

```python
CONSTANTS_DEFAULT_INTERVIEW_LEVEL = ""            # bachelor | master | "" (не задано)
CONSTANTS_DEFAULT_INTERVIEW_SPECIFIC_SHARE = ""   # 0-100 | ""
CONSTANTS_DEFAULT_INTERVIEW_DIFFICULTY = ""       # easy | medium | hard | ""
```

Параметр запуска из Moodle всегда важнее конфига. Пока значения пустые, всё работает по-старому.

## Как собирается набор

1. `count` - сколько вопросов нужно (параметр `custom_interview_question_count`, как и раньше).
2. `specific_share` (0..1) - доля специфичных. Не задана - берём как можно больше специфичных (старое поведение).
3. Если вопросов одного типа не хватает, недостачу добираем вопросами другого типа.
4. `difficulty` - желаемая сложность. Сначала берутся вопросы нужной сложности, затем ближайшие к ней
   (нужных может не хватить, поэтому в наборе бывают вопросы соседней сложности).
5. Специфичные вопросы идут по порядку номеров задач, после них общие.

## Как настроить (Moodle, LTI)

Чтобы использовать настройки, в параметры модуля в Moodle 
нужно добавить новые константы, например `interview_level=bachelor`.

| Параметр | Значения | Смысл |
|---|---|---|
| `custom_interview_level` | `bachelor`, `master` | готовый профиль |
| `custom_interview_specific_share` | число 0-100 | процент специфичных вопросов |
| `custom_interview_difficulty` | `easy`, `medium`, `hard` | желаемая сложность |

Профили (`LEVEL_PRESETS` в `question_composer.py`):

- `bachelor` - 40% специфичных, лёгкие вопросы;
- `master` - 80% специфичных, сложные вопросы.

Явно заданные доля и сложность важнее профиля. Неверное значение - ответ 400 при запуске.
Настройки сохраняются в сессии и передаются в Celery-задачу `generate_questions`.
